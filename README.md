# Rayssa Gomes

**Psicologia, acolhimento e presença digital.** 🌷

Landing page desenvolvida para apresentar o trabalho da psicóloga Rayssa Gomes, divulgar seus atendimentos online e facilitar o contato com novos pacientes.

</div>

---

### 🌸 Sobre o projeto

Uma página institucional com identidade visual delicada, navegação intuitiva e foco na experiência do usuário.

O projeto foi pensado para transmitir **acolhimento, confiança e profissionalismo**, além de apoiar a divulgação dos serviços e campanhas de tráfego pago.

### ✨ Destaques

- 📱 Interface responsiva para desktop e mobile
- 🌷 Animações e transições durante a navegação
- 💌 Seções sobre a profissional, atendimentos e contato
- 💬 Perguntas frequentes e chamadas para agendamento
- 🔎 Estrutura semântica e metadados para SEO
- ♡ Recursos de acessibilidade e respeito à preferência por movimento reduzido

### 💻 Tecnologias

`HTML5` · `CSS3` · `JavaScript` · `SVG`

Desenvolvido sem frameworks ou dependências externas, com fontes hospedadas localmente.

### 🎨 Design & experiência

Identidade visual com tons de **rosa, creme e sálvia**, tipografias **Fraunces, Jost e Caveat**, elementos orgânicos e microinterações.

O projeto inclui animações de entrada, efeitos de scroll e interações personalizadas para uma navegação mais envolvente.

### 🚀 Executando o projeto

```bash
git clone https://github.com/pricilaoliveirarocha/rayssa-gomes-psi.git
cd rayssa-gomes-psi
```

Abra o arquivo `index.html` no navegador. Não é necessário instalar dependências.
